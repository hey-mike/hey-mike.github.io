1c:T16db,## A Diagram of AI in Computer Science

![Computer Science and AI](//images.contentful.com/2swoy9jddxd7/6jhGWPq3bcl01xYsb0UoGY/381dedb846a0bb91fe7ca00b53da60e7/Computer_Science.png)

This diagram shows how Artificial Intelligence sits within Computer Science, and how different approaches to building intelligent systems are structured.

At a high level, AI can be divided into two main paradigms:
- Symbolic (rule-based) systems  
- Machine learning (data-driven systems)  

This distinction reflects a fundamental shift in how we build intelligent systems.

---

## Rule-Based System vs Machine Learning

In a rule-based system, the logic required to make decisions is explicitly defined.

- The logic is often specific to a single domain and task  
- Even small changes may require rewriting the system  
- Designing rules requires deep understanding from human experts  

Machine learning approaches this differently.

Instead of defining rules, we allow the system to learn patterns from data. This makes it more adaptable, especially for complex or uncertain environments.

A useful way to think about it:

> Rule-based systems encode intelligence. Machine learning learns it.

---

## Machine Learning — A Structural View

Machine learning can be understood through four core components:

- **Predictive learning**  
  This includes two types of tasks:
  - Predicting continuous values (e.g. future position, price)  
  - Distinguishing between categories (e.g. faces in an image)

- **Feature design**  
  A set of engineering and mathematical techniques used to represent raw data in a way that improves model performance  

  In many cases, the quality of features determines the success of a model:
  - Poor features → weak predictions, regardless of algorithm  
  - Good features → simple models can perform well  

- **Function approximation**  
  Used when we cannot explicitly define relationships in data, so the model must learn them directly  

- **Numerical optimization**  
  The underlying process that powers learning by iteratively improving the model  

These components do not operate independently—they interact during training, where data representation, model structure, and optimization combine to produce the final outcome.

---

## Cost Function

One of the key ingredients in supervised machine learning is the objective function, often called a **cost function**.

It defines what the model is trying to optimize.

- It measures how far predictions are from actual values  
- The goal is to minimize this error during training  

For example, in a regression problem, a common cost function is the mean squared error:

\[
\text{MSE} = \frac{1}{n} \sum (y_{\text{pred}} - y_{\text{actual}})^2
\]

In practice, optimization techniques such as gradient descent are used:
- The model makes predictions  
- The cost function measures the error  
- The parameters are adjusted to reduce the error  

This loop—**predict → measure error → adjust → repeat**—is what allows machine learning models to improve over time.

---

## Predictive Learning Problems

There are two main types of predictive learning problems:

1. **Regression**  
   Predicting continuous values (e.g. share price, blood pressure)

2. **Classification**  
   Predicting discrete categories  

The key difference:
- Regression → continuous output  
- Classification → discrete output  

---

## Three Types of Machine Learning

### Supervised Learning (learning from labeled data)

Supervised learning uses datasets where the correct outputs are already known.

- **Classification**
  - Predicts categorical labels  
  - Example: spam vs non-spam  

- **Regression**
  - Predicts continuous outcomes  
  - Example: relationship between study time and exam score  

Examples:
- Identifying ZIP codes from handwritten digits  
- Detecting fraud in transactions  
- Medical diagnosis from images  

A simple rule:
> If the output has continuity → regression  
> If it does not → classification  

---

### Unsupervised Learning (discovering structure)

In unsupervised learning, the data has no labels.

The goal is to uncover patterns or structure.

- **Clustering**
  - Grouping similar data points  
  - Example: customer segmentation  

- **Dimensionality reduction**
  - Reducing complexity while retaining important information  

This is often used for:
- Exploratory data analysis  
- Preprocessing for supervised learning  

---

### Reinforcement Learning (interactive learning)

Reinforcement learning focuses on agents interacting with environments.

- The agent takes actions  
- Receives rewards or penalties  
- Learns strategies over time  

Example:
- A chess engine learning optimal moves  

---

## Predictive Modeling Pipeline

In practice, machine learning follows a structured pipeline:

1. **Preprocessing**
   - Clean and prepare raw data  
   - Perform feature extraction and scaling  
   - Reduce dimensionality if needed  

2. **Learning**
   - Train the model using prepared data  
   - The model improves by minimizing the cost function  

3. **Evaluation**
   - Test performance on unseen data  
   - Ensure the model generalizes well  

4. **Prediction**
   - Apply the model to real-world data  

A key insight:

> Good predictions depend more on data quality and preparation than on model complexity.

---

## Feature Python Libraries

Common libraries used in machine learning:

- NumPy  
- SciPy  
- scikit-learn  
- pandas  
- matplotlib  

These tools enable the implementation of the concepts described above in real-world systems.

---

## Final Thought

Artificial Intelligence is not a single technique, but a structured system built on clear principles.
