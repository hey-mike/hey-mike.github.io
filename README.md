# hey-mike.github.io

This repo is the **deployment target** for [michael-luo.com](https://michael-luo.com).

- The site source lives in [hey-mike/michael-luo.com](https://github.com/hey-mike/michael-luo.com)
- CI builds the Next.js static export and pushes it to the `gh-pages` branch here
- GitHub Pages serves the `gh-pages` branch at [michael-luo.com](https://michael-luo.com)

Do not edit this repo directly. All changes should go through the source repo.
